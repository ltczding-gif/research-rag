本模板用于实验型热催化 / 异相催化论文（thermocatalysis / heterogeneous catalysis）。
默认 `_universal_rules.txt 与 _domain_quality_rules.txt` 已加载；本文件只补充正文结构、边界判断与热催化专属写法，不重设 frontmatter。
正文默认使用中文；在能提高精度时，保留必要的英文技术术语、反应器类型、分析方法与机理标签。

## 使用边界

- 适用于：以温度、压力、分压、停留时间、流速、传热传质、床层 / 搅拌条件和催化剂结构为核心变量的热催化工作。
- 不适用于：以电位、电流、电解池、离子膜、iR 补偿、法拉第效率为核心变量的电催化论文。
- 不适用于：以光照、光生载流子、带隙、光电流为核心变量的光催化或光电催化论文。
- 若文章是电辅助热催化、光热耦合、等离子体耦合或混合驱动体系，必须先判断“热催化是否是主驱动、主机理和主性能载体”；若不是，就不要套本模板。
- 若文中借用了电催化术语（例如 FE、current density、overpotential），只有在原文确有定义时才保留；不要把热催化性能强行改写成电催化话语。

## 总写作原则

- 全文遵循“证据 -> 解释 -> 含义”的顺序。
- 量化信息必须保留 `value + unit + condition`。
- 关键结论必须能回到 `[p.X]` 或 `[p.X, Fig.Y]`。
- 任何需要额外推断才能成立的内容，都要明确写成“原文未建立完整因果链，仅提供相关性 / 支持性证据”。

## 开场摘要

先写一个高密度中文摘要段，要求一段写完，不拆中英双语。
必须覆盖：
- 催化剂身份
- 反应类型
- 反应器 / 工况
- 最强证据
- 主结论

要求：
- 只要原文提供，就至少写出两个定量点
- 保留关键英文术语括号锚点，例如 conversion、selectivity、yield、STY、TON、TOF、WHSV、GHSV、residence time、operando
- 若主结论强依赖某一张关键图或某条数据链，要在段末标 `[p.X, Fig.Y]`
- 若某项关键条件缺失，直接写 `原文未提及`

## 文献基本信息

本节要简洁、可读、适合人工检索。
必须包含：
- 推荐保存文件名
- 标题
- 期刊与年份
- DOI

规则：
- `推荐保存文件名` 不能省略
- 文件名要帮助人快速识别 catalyst、reaction 和 thermocatalytic 主线
- 不要简单重复 PDF 原文件名
- `推荐保存文件名` 必须遵循共享规则中的统一骨架：`年份-期刊缩写-作者主线-核心催化体系-核心反应类型-关键机制或关键结构-解决的瓶颈问题_review_note.md`
- 这里的 7 槽位已经是热催化语义下的完整命名骨架；直接按这 7 槽位填写即可，不要依赖其他模板来理解，也不要随意改槽位顺序。
- 若 DOI 缺失，写 `原文未提及 DOI`

## 问题框定（Problem Framing）

说明本文真正想解决的热催化问题是什么。
要写清：
- paper 自己的 prior-art limitation、工艺瓶颈或机理缺口
- `性能提升`、`选择性控制`、`稳定性提升`、`工艺可行性`、`机理澄清` 这些目标中谁是主、谁是次
- 作者为什么选这条 reaction path、底物、催化剂或工况
- 若问题涉及 scale-up、低温活化、高压运行、耐毒化、耐积碳、耐烧结或连续流适配，也要明确指出

## 催化剂 / 反应体系（Catalyst / Reaction System）

这一节只保留那些会影响解释和复现的系统信息，不要堆 methods。
包括：
- 催化剂身份：组成、support、metal / oxide / acid-base site、晶相、粒径、形貌、孔结构、预处理状态
- 工作态信息：若原文显示催化剂在反应中重构、相变、还原 / 氧化或烧结，要同时写初始态与工作态
- 反应体系：底物、共反应物、稀释气、溶剂、助剂、抑制剂、平衡气、载气、含水 / 含氧环境
- 反应器类型：batch、semi-batch、fixed-bed、packed-bed、fluidized-bed、CSTR、microreactor、trickle-bed 或 other，并说明为什么它对本文结论重要
- 操作窗口：温度、压力、分压、流量、搅拌、床层高度、颗粒尺寸、停留时间、WHSV、GHSV、空速、接触时间、预还原 / 预氧化 / 煅烧 / 活化条件

如果高性能建立在特定边界条件上，要明确写清，例如高压、短接触时间、特定湿度、特定溶剂比例、特定稀释比或特定进料纯度。
若存在传热 / 传质限制争议，也要说明是否有粒径、搅拌、流速、床层或稀释验证。

### 热催化真实性与传递伪影排除（Reactor realism / transport artifact check）
- 反应器构型不能只停留在名词层面，要写出它在本文中承担的热管理职责：是压低床层温差、减弱热点（hot spot）、缩短停留时间、提升外部传热，还是为了把体系尽量推入动力学控制区
- 若为固定床 / packed-bed / tubular reactor / microreactor / fluidized-bed / slurry / CSTR / batch / trickle-bed / monolith / structured catalyst，需明确它与放热、吸热、相平衡或副反应的耦合关系；若原文没有解释，直接写 `原文未提及`
- 优先检查是否报告床层轴向 / 径向温度剖面、壁温与床温差、热电偶位置与校正、热启动 / 冷启动、稳态判定、采样点与分析延迟；若只有单一炉温或出口温度而无床内温度信息，要把这当作热失真风险而非自动接受为 intrinsic data
- 若作者声称不受传热 / 传质限制，应尽量核查是否做了流速 / 搅拌速率、粒径、床高、稀释比、催化剂装填量、颗粒分布、接触时间、WHSV / GHSV / space velocity 的敏感性测试；若这些变量变化会改变 conversion、selectivity、rate 或 apparent Ea，则不能简单按“内在动力学”解读
- 对于强放热或强吸热体系，必须提醒审稿人视角下的关键问题：热点、冷点、点火 / 熄灭（ignition / extinction）、温度梯度导致的选择性漂移、传热-反应耦合导致的表观速率偏移，均可能比活性位本征差异更大
- 如果原文使用 structured catalyst、coating、foam、honeycomb、washcoat、membrane reactor 或其他高传热几何，要说明几何改进是否同时改变了压降、床层利用率、几何归一化口径和比表面积基准；不能把“更强传热”与“更强本征活性”混写成同一个结论
- 若文中只报告了单点条件、短时间窗口或最有利窗口，而没有给出操作窗口、温度扫描和传递极限排除，必须写清该结论更像条件点表现，不等于可直接推广的 intrinsic kinetics

### 物料衡算 / 元素衡算 / 副产物闭环
- 气相体系优先检查碳衡算、氢衡算、氧衡算、氮衡算是否闭合；液相体系优先检查底物、溶剂、溶解气体、挥发份、冷凝份、洗脱份、残渣和积碳是否都被纳入
- 若作者只报目标产物而未交代副产物、未反应底物、气液分配、壁面沉积或尾气组分，不要默认 selectivity / yield 已经闭环；要明确写 `部分闭环` 或 `原文未提及`
- 若文中给出的是按已检测产物归一化的“表观选择性”，必须提醒它不等于完整元素闭环；若总收率、总碳平衡或关键副产物缺失，则不能把 headline 数字当成完全守恒证据
- 若物料衡算只在 SI 中出现而当前无法核实，写 `SI未上传/原文未提及，无法核实`，不要用经验补齐

## 反应器 / 条件 / 定量（Reactor / Conditions / Quantification）

这一节专门回答“怎么测、怎么算、为什么可信”。

### 反应器与操作条件
- 反应器构型必须写清楚，不能只写“固定床”或“流动体系”
- 说明加热方式、温控方式、采样位置、背压方式、是否在线分析、是否稳态后取数
- 若原文比较不同工况，要说明这些工况是单变量变化，还是同时改动了温度、流量、组成、压力或催化剂装填

### 产物与底物定量
- 气相产物：GC / GC-MS / online MS / micro-GC / FTIR 等方法、色谱柱、检测器、标定方式、内标 / 外标、校准曲线
- 液相产物：NMR / HPLC / IC / titration / other 的分析方法、溶剂、内标、峰归属与定量逻辑
- 固相或残留物：积碳、沉积、浸出、失活副产物、金属流失、表面覆盖物等若有测，也要写
- 若原文报告物料衡算、碳衡算、氢衡算、氮衡算或元素闭环，必须保留；若缺失，要写 `原文未提及` 或 `SI未上传/原文未提及，无法核实`

### 计算口径
- 说明 conversion、selectivity、yield、productivity、STY、TON、TOF、rate、space velocity 的定义与归一化基准
- 若作者用了质量归一化、金属归一化、表面积归一化、位点归一化或几何面积归一化，必须写清
- 若不同图表正文使用了不同基准，要点出来，不能默认可直接比较
- 若存在误差棒、重复实验、标准偏差、置信区间或检测下限，也要保留

### 条件在文中的作用
- 不只写“条件是什么”，还要写“这个条件在本文里承担什么角色”：是筛选催化剂、锁定速率区间、触发选择性切换、验证传质极限、测试耐久性，还是机理探针
- 若作者没有解释条件的物理意义，要明确指出，而不是替作者补解释

## 核心证据（Core Evidence）

这一节写全篇最强的证据链，但不要机械转写图注。
- 优先写真正支撑主张的关键性能图、结构图、对照图、控制实验和前后表征
- 逐条说明“图上直接看到什么”“作者据此想证明什么”“这张图单独不能证明什么”
- 不要只写图号，必须写图真正证明了什么
- 若某个结论要靠多个 panel 组合才成立，要把组合逻辑写出来
- 若某个图只是 schematic、装置图、路线图或流程图，也要说明它在论证链中的职责

## 性能指标（Performance Metrics）

把最重要的热催化性能指标完整写全，优先用中文解释，英文术语保留括号锚点。

优先覆盖：
- 转化率（conversion）
- 选择性（selectivity）
- 收率（yield）
- 产率 / 生产率（productivity）
- 空时收率（STY）
- TON / TOF
- 反应速率（rate）
- 表观活化能（apparent Ea）
- 反应级数（reaction order）
- 稳态窗口内的性能保持情况

要求：
- 每个指标都要带数值、单位和工况
- 若报告多个产品，要分产品写清，不要合成一句“选择性很好”
- 若性能只在特定 conversion、温度或流量窗口下成立，要写明这是受限窗口还是主结论窗口
- 若 rate、TOF、apparent Ea 或 reaction order 是在可能存在温差、热点、传质受限、床层非均温或未证实稳态的条件下测得，要标明这是 apparent 结果，不能直接写成 intrinsic kinetics
- 若不同图表或不同文献采用了不同归一化基准（per gram、per metal、per site、per reactor volume、per external area），必须明确说明基准不同，不能直接并排行列
- 若作者只挑最优点、不交代完整 conversion map 或温度窗口，就要提醒这类数值可能带有最优点偏差，而不是全域代表性
- 若 benchmark、baseline 或 literature comparison 是主结论的一部分，必须判断是否 apples-to-apples：
  - 是否同一反应器类型
  - 是否同一 feed / solvent / pressure / temperature 口径
  - 是否同一空速 / 停留时间 / 装填量 / 底物浓度
  - 是否同一分析方法与归一化基准
  - 是否同一稳定性时长或评价窗口
- 进一步还要核对是否同一热管理条件：加热方式、炉温 / 床温定义、壁温控制、是否存在显著温差、是否有外循环或内部换热结构
- 进一步还要核对是否同一接触时间与空间速度口径：residence time、WHSV、GHSV、空床时间或有效接触时间的定义是否一致
- 进一步还要核对是否同一进料纯度与杂质背景：微量水、氧、硫、氯、氮、芳香族、蜡质、溶剂残留等都会显著影响热催化性能与失活路径
- 进一步还要核对是否同一催化剂装填与床层状态：粒径、稀释比、床高、压实程度、黏结剂、载体、涂层厚度、结构化填充物、是否有预还原 / 预氧化 / 预活化
- 进一步还要核对是否同一数据截点与窗口：低转化区、稳态区、诱导期、衰减后半段、再生后首圈数据都不能直接混成一个排名
- 若 benchmark 的优劣可能来自更强热管理、更低压降、更短接触时间或更少副反应窗口，而不是本征活性优势，要明确写出这一层边界
- 若文献对比混用了 conversion、yield、rate、STY、TOF、TON、productivity 等不同指标，要说明这些指标的物理含义不同，不能被简单合并成单一“性能更好”
- 若对比对象只在某一最优点上取值，而本文是全窗口数据，应提示这类比较存在 cherry-picking 风险
- 若不可比，不要直接写“显著更优”，而要写清比较边界

## 机理图景（Mechanistic Picture）

这一节必须把“观测证据”和“推断机理”分开写。

### 观测证据
- 只写原文直接可见的现象：operando / in situ 谱图、结构变化、吸附行为、活性位演变、反应中间体、动力学曲线、同位素信号、毒化响应等
- 若有 operando / in situ XAS、XRD、DRIFTS、Raman、IR、TEM、SSNMR、EPR、MS、TPD、TPSR、KIE、同位素标记、脉冲实验或微观动力学数据，要写清各自提供了什么证据
- 若原文做了 DFT 或 microkinetic modeling，要明确它补的是位点识别、能垒排序、覆盖度、选择性分叉还是速率控制步

### 推断路径
- 只有当因果链真正成立时，才写 `A -> B -> C`
- 若只是相关性增强，必须明确写“作者据此推断”或“更稳妥地说是相关性支持”
- 若机制涉及活性位、界面效应、酸碱协同、氧空位、金属-载体相互作用、吸附 / 脱附平衡、传质 / 传热耦合或重构，请拆开写
- 若原文没有建立完整闭环，就直接说明缺哪一环：operando、同位素、控制实验、时间分辨、结构敏感性或理论支撑

### 边界与 caveat
- 指出机理证据最容易被过度外推的地方
- 若作者把“最可能机理”写成“已证实机理”，要降语气并指出边界
- 若机制只在某一组温压和进料窗口内成立，必须写清，不要外推到更广工况

## 失活 / 稳定性 / 再生（Deactivation / Stability / Regeneration）

这一节专门写失活、耐久、再生和复用。
- 稳定性要区分：短时稳态、长时 time-on-stream、循环使用、热冲击、气氛切换、停开机、再生后复用
- 必须说明性能衰减体现在哪：转化率掉了、选择性漂了、产率降了、积碳增了、金属流失了、粒径变大了、相变了，还是活性位被毒化了
- 常见失活路径要明确点名：sintering、coking、poisoning、phase segregation、support collapse、leaching、volatilization、surface reconstruction failure 等
- 若作者做了 regeneration，要写清方式、恢复幅度、是否回到 fresh baseline、能重复几次、恢复是否稳定
- 若只有短窗口或单次再生，必须明确局限，不要把它写成“长期稳定”
- 进一步还要区分 regeneration 是 operating strategy（工艺策略）还是 rescue step（失效补救）；如果再生本身成为工艺的一部分，就不能把再生后的性能恢复简单等同于“天然长寿命”
- 要写清 regeneration 类型：oxidative / reductive / steam / solvent / thermal / plasma / microwave / chemical washing / in-situ 或 ex-situ；不同路径对结构、粒径、酸碱性、金属分散度和载体完整性的影响不同
- 如果 regeneration 后只恢复 activity 但 selectivity、诱导期、失活速率或结构表征没有回到 fresh baseline，必须明确说明这是“部分恢复”而不是“完全可逆”
- 若作者只展示单次再生成功，而没有多轮循环、再生间隔、累计衰减和再生前后结构一致性，就不要把它写成稳定耐久证据
- 若失活曲线出现 induction period、快衰减段、慢衰减段或再生后 hysteresis，要尽量保留这些时间结构，不要只报平均寿命
- 若表征显示积碳、烧结、毒化、相分离、挥发、支撑体坍塌、晶相转变或表面包覆，但作者没有把它和性能衰减一一对应，要明确写出“失活路径已提示但未完全闭环”

## 陷阱扫描（Trap Scan）

这是强制核查项，不能省略。
请逐项检查并明确写出：
- 是否误用了电催化指标或光催化话语：[present / absent / mixed]
- 是否缺少完整物料衡算、元素衡算或关键副产物闭环：[complete / partial / missing / not applicable]
- 是否缺少关键对照实验、空白实验或传质 / 传热排除实验：[adequate / incomplete / absent]
- 反应器、温度、压力、停留时间、流量、装填量、搅拌与预处理是否交代清楚：[clear / partly clear / unclear]
- 定量方法与校准是否可核实：[sufficient / SI未上传，无法核实 / missing]
- benchmark 是否公平：[apples-to-apples / partially comparable / not comparable]
- 稳定性结论是否只建立在短窗口或最有利窗口上：[robust / limited-window / overclaimed]
- 失活或再生路径是否真的被分析：[well-supported / hinted only / not analyzed]
- 观测、解释、推测是否分层清楚：[clear / partially mixed / heavily mixed]
- 关键参数是否先解释物理意义再报数值：[yes / partially / no]
- 是否报告床层温差、热点 / 冷点、流速敏感性或粒径敏感性，从而排除了明显的传热 / 传质伪影：[yes / partially / no]
- 再生后的性能是否与 fresh baseline、再生次数和结构变化一起被比较：[well-supported / partially supported / not supported]

若某个主张明显超出直接证据，必须点出来。
若作者把模型条件或短窗口条件下的结论外推成工艺可行性，也必须明确标注外推边界。

## 主观打分

每个维度都要给分，并用一句话说明理由，理由必须能回到正文或图证。

- **创新性（0-10）**：[score] — 说明是概念推进、体系突破、方法突破，还是边际改进
- **实验严谨度（0-10）**：[score] — 明确写出因对照、校准、衡算、误差棒、重复性、条件控制而加分或扣分的地方
- **证据链闭环度（0-10）**：[score] — 说明主结论是直接证据闭环，还是主要依赖推断
- **工艺 / 工业潜力（0-10）**：[score] — 结合高温、连续流、寿命、再生、放大可行性与条件敏感性判断

评分锚点：
- 9-10：能够明显重塑该子领域判断标准的 field-shaping 工作
- 7-8：扎实、清楚、推进明确的 solid meaningful advance
- 5-6：合格但推进幅度有限，或证据链有明显局限
- 3-4：存在明显方法学缺陷、衡算问题或证据闭环问题

## 核心结论总结

用一个段落收束全文，必须同时写出：
- 这篇论文对其子领域真正做出的贡献
- 最重要的 caveat、复现风险或条件依赖性
- 后续读者复用或扩展时最该警惕的点
- 哪些结论可以在相近边界条件下复用，哪些不能直接外推到更高温、更高压、更长寿命、不同反应器或不同 feed
- 如果论文只证明了“相关性”而不是完整机理，也要在这里说清楚

## 写作规则

- 所有事实性表述都只基于当前附加文档和共享规则，不写背景知识补全
- 缺失的条件、方法、数值或边界，统一写 `原文未提及`
- 任何需要 SI 才能核实但当前无法核实的内容，统一写 `SI未上传/原文未提及，无法核实`
- 不要把热催化性能写成电化学性能，也不要把光照驱动写进来
- 若正文涉及 figure 或 panel，必须写“它证明了什么”，不能只给图号
- 若正文涉及比较，必须显式检查 benchmark comparability
- 若正文涉及稳定性、耐久性或工艺可行性，必须尽量讨论失活路径或验证边界，不能只重复 headline number
- 若原文没有建立完整机制链，就直接说明，不要补写想象出来的闭环
