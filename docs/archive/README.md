# Archive

Historical records from earlier development: reverse-engineering
investigations, sub-agent audits, design plans and ADRs, packaging plans and
status snapshots. They are kept verbatim as evidence of what was known and
decided at the time.

**Not maintained.** File paths, commands, defaults and links inside these
documents may be out of date. The [README](../../README.md), the current
[documentation index](../README.md) and the live code take precedence.

| Path | Contents |
|---|---|
| `investigation/` | Original reverse-engineering reports of the pre-release system (2026-05) |
| `audits/` | Snapshot code reviews at specific commits |
| `plans/` | Design documents and ADRs, including the RAG upgrade and terminal-first ADRs |
| `ARCHITECTURE.md`, `COMPONENTS.md`, `Project_Architecture_Blueprint.md` | Earlier architecture write-ups |
| `PACKAGING-PLAN.md`, `POLISH-EVALUATION.md`, `INVESTIGATION-INDEX.md`, `architecture-discussion-2026-05-08.md` | Pre-release packaging and polish planning |
| `STATUS-2026-05-staging.md` | Status log from the staging period before the first public release |
